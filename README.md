## about me

i'm oshia, a software engineering / information technology student from jakarta.

i started coding in **2019**, originally messing around with game servers. since then i've worked on a bunch of different things — game servers, desktop utilities, web stuff, hosting, and now android apps.

i graduated from **smk pembangunan jaya** in 2025, where i studied software engineering (pplg). i'm currently studying **s1 teknologi informasi at telkom university jakarta**.

most of what i build comes from stuff i actually need or want to use myself.

## currently building

### 🔥 [fireflycollege](https://github.com/oshia26/FireflyCollege)

a local-first android college organizer i made because i kept forgetting assignments and group information while juggling university and other projects.

built with:

* kotlin
* jetpack compose
* material 3
* room
* local storage
* no backend

it keeps track of courses, deadlines, countdowns, and which group i'm in for each course.
